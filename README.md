# Pesona Nusantara

Pesona Nusantara adalah website sederhana untuk mengenalkan beberapa destinasi wisata di Indonesia. Pengunjung bisa melihat halaman utama dan membaca informasi mengenai setiap destinasi.

Proyek ini dibuat menggunakan HTML, tanpa framework atau proses build. Beberapa gambar dan peta ditampilkan dari layanan online, jadi koneksi internet diperlukan agar semuanya dapat dimuat.

## Destinasi

Informasi yang tersedia mencakup:

- Raja Ampat
- Jakarta
- Medan
- Labuan Bajo
- Gunung Bromo
- Candi Borobudur
- Danau Toba
- Ubud, Bali
- Nusa Tenggara Timur
- Jawa Tengah

Di halaman utama juga terdapat navigasi destinasi, kontak WhatsApp, dan testimoni.
