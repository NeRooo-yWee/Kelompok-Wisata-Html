# Pesona Nusantara

Pesona Nusantara adalah website sederhana untuk mengenalkan beberapa destinasi wisata di Indonesia. Pengunjung bisa melihat halaman utama, membaca informasi tiap destinasi, dan menemukan informasi paket wisata serta pemesanan.

Proyek ini dibuat menggunakan HTML, tanpa framework atau proses build. Beberapa gambar dan peta ditampilkan dari layanan online, jadi koneksi internet diperlukan agar semuanya dapat dimuat.

## Destinasi

Informasi yang tersedia mencakup:

- Raja Ampat
- Jakarta
- Labuan Bajo
- Gunung Bromo
- Candi Borobudur
- Danau Toba
- Ubud, Bali

Di halaman utama juga terdapat bagian kalender acara, paket wisata, formulir pemesanan, testimoni, dan ulasan komunitas.
